All data, notebooks, models, forecasts, configurations, and reports were accessed and operated within the client's Azure environment.

The project used the client-provided Azure Databricks workspace and Azure Storage capabilities. Data and implementation resources remained within that controlled environment and were not exposed as public APIs or external services.
