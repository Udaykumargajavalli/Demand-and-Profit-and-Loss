## Artifact Categories

- Prepared training datasets.
- Feature definitions.
- Trained candidate models.
- Model parameters and metrics.
- Validation outputs.
- Selected champion or ensemble configuration.
- Forecast outputs.
- Historical accuracy reports.
- Run metadata and configuration snapshots.

MLflow supported experiment and model lifecycle management. Azure Storage retained configuration, forecast outputs, and reporting datasets.
